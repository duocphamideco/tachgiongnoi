Tách audio YouTube hoặc tạo mẫu giọng WAV để Voice Clone

TÁCH AUDIO TỪ LINK YOUTUBE

Dán link → bấm TÁCH AUDIO → nghe thử → tải MP3.
⬇️ TẢI FILE MP3
Chỉ xử lý video mà anh sở hữu hoặc được phép tải/chuyển đổi.

TÁCH MẪU GIỌNG → SAYDI VOICE CLONE

Upload video, chọn đoạn ngắn 5–30 giây, tạo WAV sạch để clone giọng Chrome / Edge
Ví dụ 12.5 = lấy từ giây 12,5.
Mẫu ngắn giúp file nhẹ và dễ clone.
Lọc nhẹ, không phải AI tách nhạc hoàn toàn.
✅ Mẫu giọng đã sẵn sàng
Voice Clone: trình duyệt không cho website IDECO tự gắn file vào ô Upload của SayDi. Vì vậy quy trình là: tạo WAV → tải WAV → mở SayDi Clone → chọn file WAV vừa tải.
